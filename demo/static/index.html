Horus · clear-air turbulence radar · synthetic preview

Finding rough air in the signal every airliner already sends.

Each aircraft broadcasts its vertical rate. When it flies through turbulence, that number jitters. Horus measures the jitter, removes the rounding that fakes it, and maps where the air is rough — with no extra sensors.

04The maths

The key idea: undo the rounding.

ADS-B rounds vertical rate to 64 ft/min steps. That rounding looks like turbulence unless you remove it.

σ²corr = σ²raw − Δ²/12  ·  Δ = 64 ft/min

True
Measured (raw)
Corrected

Expected values from Sheppard's approximation (σ²raw ≈ σ² + Δ²/12). In our synthetic tests it holds within 2% for σ ≥ 40 ft/min.
